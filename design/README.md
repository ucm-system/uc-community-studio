# UC Community visual identity

The selected direction is **Open Commons**, the third visual concept in `concepts/03-open-commons.png`: bright blue/green graphics, structured information blocks, and a standalone UCM graphic mark.

## Assets

- `assets/ucm-symbol.png` is an exact transparent crop of the original UCM image's left graphic (811 × 766 pixels). Source: `ModelEngine-Group/unified-cache-management`, `docs/source/logos/UCM-light.png`. The UCM / Unified Cache Manager wordmark is excluded.
- `../public/assets/open-commons-motif.png` is a 1024 × 1536 ImageGen-created white, mint and cobalt decorative ribbon. It contains no logo or text. Poster text remains editable HTML.
- Original concept boards in `concepts/` are design references, not templates or final 4K outputs.

## Current design decisions

- Preserve Inter + Noto Sans SC typography and the original editor styling.
- Add blue/mint geometric decorations at the poster edges, clear of text.
- Emphasize U, C and the initial C in UC Community with blue/teal/violet, without resizing the letters.
- Emphasize the initial T in Thursday, Tech and Talk at 1.6× surrounding text; use the same accent hues, with lighter variants on the blue panel.
- Portrait PNG: 2880 × 3840. Landscape PNG: 3840 × 2160.
- Both formats share the same activity content and have individually composed layouts.

The sample activity is explicitly labeled as an example. It does not represent a scheduled community event.
